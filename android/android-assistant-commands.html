Assistant Commands

Voice commands.
Coming with launch.

ClickTrack Pro for Android is planning Google Assistant and App Shortcuts support that mirrors the 35 Siri commands available on iOS today. The categories and examples below reflect our current plan and may change before release.

Free Available to all users
Pro Requires ClickTrack Pro
Planned Not yet implemented
Voice and Shortcuts support is on our Android roadmap but isn't built yet. The cards below are representative examples drawn from the iOS command set — see the full 35-command iOS list for the current reference implementation.

Playback

Set Tempo
FreePlanned
Sets the metronome tempo and starts playing.
"Hey Google, set tempo in ClickTrack" "Hey Google, start the metronome in ClickTrack"
Stop Metronome
FreePlanned
Stops the metronome.
"Hey Google, stop ClickTrack"
Adjust Tempo
FreePlanned
Increases or decreases the tempo by a number of BPM.
"Hey Google, adjust tempo in ClickTrack"
Set Time Signature
FreePlanned
Sets the metronome time signature, for example 3/4 or 6/8.
"Hey Google, set time signature in ClickTrack"

Presets

Apply Preset
ProPlanned
Applies a saved tempo preset and starts playing.
"Hey Google, play {preset} in ClickTrack"
List My Presets
ProPlanned
Lists all of your saved presets by name.

Practice

Start Practice Session
ProPlanned
Starts a new practice session in ClickTrack.
"Hey Google, start practice in ClickTrack"
How Much Have I Practiced?
ProPlanned
Reports today's practice time and your current consecutive-day streak.

Tuner

Look Up Tuning
ProPlanned
Tells you the string notes for any guitar or bass tuning.

Band Sync

Start Band Sync Session
FreePlanned
Starts hosting a band sync session. Other devices can join and follow your tempo.
What's My Band Sync Status?
FreePlanned
Reports whether band sync is active and how many devices are connected.
